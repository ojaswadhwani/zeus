# Security reporting

Use the repository's private vulnerability reporting form for suspected vulnerabilities. Include the affected version, relevant details, and the impact. Keep production data, credentials, and customer information out of reports.

Before the first public tag, maintainers must enable private vulnerability reporting and assign a maintainer to triage submissions. The embedded alpha assumes a trusted operator and an existing directory under that operator's control. Storage checksums detect accidental corruption. See the [security design](docs/security-and-ai.md) for planned network controls.
